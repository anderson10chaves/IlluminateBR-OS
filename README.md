# 🇧🇷 OS IlluminateBR

> **Missão:** Unificar a estabilidade, a compatibilidade universal de softwares e a alta performance em um Sistema Operacional brasileiro moderno, fluido e pronto para desenvolvedores.

---

## 🚀 Propósito e Pilares

O **OS IlluminateBR** nasce para resolver a fragmentação do ecossistema Linux através da unificação:

1. **Unificação de Pacotes:** Suporte nativo e transparente a Flatpak, AppImage e gerenciador de pacotes nativo de alto desempenho.
2. **Pronto para Desenvolvedores:** Suporte imediato a Docker, KVM, Flutter, Java, Node.js e IDEs modernas sem necessidade de setups complexos.
3. **Interface Flutuante e Elegante:** Cinnamon Desktop refinado com temas coesos (estilo macOS/WhiteSur) para máxima produtividade sem abrir mão da leveza.

---

## 🛠️ Estrutura do Repositório

- `build.sh`: Script principal para automação da compilação da ISO.
- `profile/`: Configurações do perfil do sistema, lista de pacotes e arquivos de sistema (`airootfs`).
- `scripts/`: Scripts de pós-instalação, personalizações do Cinnamon e otimizações de desempenho.
